Scale Honesty Rules

Because the farm AOI (1.34 km²) is smaller than native grid pixels (POWER ~55 km, GPM ~11 km, SMAP 9 km), raster_processor.py uses nearest_grid_cell_containing_aoi and enforces a 0.25° (~27 km) swath distance check so SMAP orbital miss days report no_overpass_covering_aoi instead of matching a distant pixel.

7. Standardized Data Schema & Quality Control

Quality Status Labels

  • VALID All checks passed; no missing or out-of-range values.
  • VALID_WITH_WARNINGS Extreme weather (≥ 100 mm/day rain, ≥ 40 °C), deduplication, or SMAP bitmask bit-0 set (values retained).
  • INCOMPLETE Missing values (-999, -9999, or no_overpass_covering_aoi) preserved as null — never coerced to 0.
  • INVALID Zero valid records or invalid physical bounds (e.g., RH > 100%).

8. TERRA FastAPI Reference

Start the server with python main.py --action serve --port 8000 and test live endpoints below (or open http://localhost:8000/docs): 

Click "Send Request" while `python main.py --action serve` is running locally.
GET /observations — Filter by start_date, end_date, dataset, variable, aoi_id, quality_status.
GET /observations/precipitation — Separates daily accumulation (mm/day) from rate (mm/hr).
GET /observations/soil-moisture — Distinguishes satellite volumetric m³/m³ (SMAP) from modeled wetness indices (POWER).
GET /observations/temperature — Daily mean, max, and min air temperature (degC).
GET /observations/vegetation — Reserved for Phase 6 MODIS MOD13Q1 NDVI/EVI.

9. Setup, Earthdata Auth & CLI Commands

# Install dependencies & configure Earthdata token
pip install -r requirements.txt
cp .env.example .env
# Edit .env and set EARTHDATA_TOKEN=... (approve GESDISC + NSIDC Cumulus Data on urs.earthdata.nasa.gov)

# Run full pipeline for a 3-day window
python main.py --start-date 2024-01-01 --end-date 2024-01-03

# Individual actions
python main.py --action discover
python main.py --action download
python main.py --action process
python main.py --action serve --port 8000

10. Tests & Troubleshooting

8 / 8 Passing Run automated suite: pytest -v

  • 401 / 403 Error Approve NASA GESDISC DATA ARCHIVE, NSIDC Cumulus Data, and NSIDC_DATAPOOL_OPS in your URS profile.
  • Swath Gap no_overpass_covering_aoi in SMAP is expected on days when SMAP's 2–3 day tropical orbit misses Lipa.
  • 3.5 mo Lag Switch preferred_product in config/farm_config.yaml from GPM_3IMERGDF to GPM_3IMERGDL for ~14-hour latency.
